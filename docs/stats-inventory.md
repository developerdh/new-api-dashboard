# 统计能力清单

看板已支持统计的速查表：一卡一行，说明每张卡能按什么维度统计、展示什么指标、口径覆盖哪个时间段。**新增、调整或下线统计卡片 / 图表 / 指标时，必须同一次提交更新本文件**（开发规则 R4，见 [dev-rules.md](./dev-rules.md)）。设计口径以 [方案.md](./方案.md) 为唯一权威，两者不一致时以方案为准并触发同步。

> 「随全局区间」指是否随页面顶部时间筛选器变化；固定窗口卡自带独立区间。

## 全局总览 `/dashboard`

| 卡片/图表 | 统计维度 | 指标 | 时间口径 | 随全局区间 |
|---|---|---|---|---|

## 口径速查

- 分桶均按东八区自然小时 / 日 / 周（周一锚定）/ 月；区间左闭右开。
- 额度取 `quota_data`（≤ 5 分钟延迟），请求数与 Token 输入 / 输出拆分取 `logs` 消费流水。
- 统计一律排除 admin 账号；用户详情各卡限定该用户。
- 会话看板（dashcam 会话与监控记录）为只读采集展示，不属于统计口径，不在本清单。
