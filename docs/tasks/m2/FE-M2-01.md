## 目标
`/dashboard` 布局与全站共享件就绪：导航、明暗主题切换（CSS 变量 + localStorage）、时间范围/粒度选择器、ECharts 与 Tremor 图表封装、统一数据获取 hook，M2 其余卡只做页面拼装。

## 本任务关键口径摘要
- 布局：顶部导航（总览 `/dashboard` ｜ 模型分析 `/models`）+ 全局筛选栏；响应式（Tremor grid 断点）。
- 主题：`ThemeToggle` 亮/暗/跟随系统，CSS 变量 + `localStorage('theme')`，无 next-themes 新依赖（§7.3 既定实现方式）；ECharts 实例随主题重绘（监听 data-theme 属性）。
- 时间范围选择器：预设今日/近7天/近30天/本月 + 自定义区间 → 写 URL searchParams `start/end`（Unix 秒）；粒度切换 day/week/month 同步 `granularity`。全站状态以 URL 为唯一载体（可分享、可快照，为 BE-M3-03 服务）。
- ECharts 封装：`src/components/charts/EChart.tsx`——client 组件、`next/dynamic ssr:false`、option 声明式传入、容器 ResizeObserver 自适应；导出按钮插槽（FE-M3-02 接入点）。
- 数据 hook：`src/lib/use-api.ts`——fetch + loading/error/数据缓存态 + `refetchInterval` 可选轮询；无 SWR/react-query 新依赖。
