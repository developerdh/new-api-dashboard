# 用户反馈登记（FEEDBACK）

> 作用：用户临时反馈的 BUG / 新需求的唯一登记入口。只登记待处理反馈，不承载修复过程、方案与结论。
> 机制：
> 1. 用户提出反馈 → 在下表追加一行，编号递增（F-001、F-002…）。
> 2. 仅在用户明确指示时转出，三个去向：①立任务卡（新卡「变更记录」首行注明来源反馈编号）；②转 `BACKLOG.md` 待排期节；③核实不成立/决定不做 → 直接删行。
> 3. 转出后立即删除本表对应行——本文件只保留未处理反馈；无待处理反馈时表格为空属正常状态。BUG 不进 BACKLOG：要么转卡修，要么删。
