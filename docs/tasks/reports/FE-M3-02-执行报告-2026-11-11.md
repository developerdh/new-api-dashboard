## 3. 关键决策

1. **运行时来源**：不引入 CDN；新增本仓库只读端点输出 `node_modules/echarts/dist/echarts.min.js`，导出时 fetch 后内联（自包含、离线可打开）。
2. **体积取舍**：运行时约 1.12MB + option，接受该体积换「保留 tooltip/图例/缩放」硬判据；不做外链/压缩优化。
3. **formatter 丢失**：`getOption()` 中函数（tooltip/axis formatter）无法 JSON 序列化，导出后退回 ECharts 默认格式化；数据与交互不受影响（变更记录留痕）。
4. **文件名**：`<scope>-<start>_<end>.html`（URL 参数），无参数回落 `scope-YYYY-MM-DD.html`；scope 仅保留字母数字/点/下划线/连字符。
5. **运行时路径坑**：`require.resolve` 在 Next 打包后返回模块 id（数字）导致 500；改为 `process.cwd()/node_modules/...` 读取（`next start` 下可用）。
