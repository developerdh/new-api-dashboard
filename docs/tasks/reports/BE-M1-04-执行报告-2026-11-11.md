## 3. 口径定稿

1. **limit**：缺省 20、上限 100；>100 由 service 层 400（path=limit），不放宽公共 schema 的 500 上限。
2. **缓存 key 含 limit**：`usersRanking:all:<start>:<end>:all:all:limit=N`；TTL 120s（§6.3(3)）。
3. **排序稳定**：`total_quota DESC, user_id ASC`，同额用户顺序确定。
4. **username 改名**：按 (user_id, username) 聚合后取「区间内消耗最大」的名称；不把 username 放进 Top N 分组键，避免同 id 多行挤占名额。
5. **请求数**：先取 Top N user_id，再 logs `COUNT(*) GROUP BY user_id`（IN 参数化）；Top N 为空时不发后续查询。
6. **空结果**：`data.rows = []`，不返回 null。
