## 3. 口径定稿

1. **活跃天数**：`COUNT(DISTINCT (created_at + 28800) / 86400)`（东八区自然日、整数分桶）；东八区无夏令时，与 JS `shanghaiDate` 口径一致。
2. **空数据不 404**：用户不存在或区间无记录 → `ok:true` + 全 0 / 空数组，避免探测用户存在性。
3. **models**：`GROUP BY model_name`、消耗降序 + model_name 兜底；`promptShare/completionShare` 分母为 0 记 0（不产生 NaN）。
4. **recent**：该用户最近 50 条 logs（`created_at DESC`），**不按区间过滤**（「最近使用」是全局最近记录）。
5. **缓存**：overview/trend 复用 `userTrend`（30s）、models 用 `modelDist`（30s）；key 含 userId（不拼进 modelName）。
6. **granularity**：单用户 trend 缺省 day；overview/models 的 `meta.granularity` 固定 null。
