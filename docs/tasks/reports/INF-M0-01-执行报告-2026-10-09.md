## 3. 环境适配决策（均不涉及方案口径变更）

1. **无外网环境**：npm 走内网 Nexus 私服；shadcn 官方 registry 与 Google Fonts 均不可达。故 shadcn 组件源码手工落库（等价于 CLI 产物）、`components.json` 手工落地；字体改用系统字体栈（`next/font/google` 会在构建期联网失败）。
2. **Next 16 无 `postcss.config.mjs`**：Tailwind v4 由 `@tailwindcss/turbopack` loader 接入（Next 16 模板默认），比卡片预期少了该文件。
3. **Tremor × React 19 peer 冲突**：`@tremor/react` 3.18.7 peer 声明 `react ^18`，用 `pnpm.peerDependencyRules.allowedVersions` 放行 React 19 —— `pnpm.overrides` 只能改依赖版本、无法改写 peer 范围，故取前者；未回退 React/Tailwind 版本。
4. **Turbopack 与 pnpm 链接布局**：默认 isolated 布局下 `next build` 报 `Could not find the Next.js package (next/package.json)`（Turbopack 不解析 pnpm 的 junction；用新建空白 create-next-app 工程复现，非本项目独有）。固定 `.npmrc` `node-linker=hoisted` 后构建正常。
5. **Next 16 `cacheComponents`**：`/users/[id]` 直接 `await params` 会导致预渲染构建失败，改为「静态外壳 + `<Suspense>` 流式渲染动态段」，构建通过且路由呈 Partial Prerender。
