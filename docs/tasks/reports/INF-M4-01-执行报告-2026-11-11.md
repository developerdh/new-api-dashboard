## 3. 关键决策

1. **双目标镜像**：默认 `runner` 保持 slim（不装浏览器）；`runner-snapshot` 单独承载 Playwright + chromium，避免所有部署都背数百 MB。
2. **standalone + 显式 COPY**：`/api/echarts/runtime` 按 `process.cwd()/node_modules/echarts/dist/echarts.min.js` 读取，standalone 依赖追踪不包含该文件，Dockerfile 显式 COPY（FE-M3-02 遗留的打包注意点）。
3. **不置 blocked**：卡内建议「无 Docker 置 blocked」，按本会话机制（同 BE-M0-03）改为代码交付 + done + LH-09 双向登记；实机 build/up/快照验收待环境就绪。
4. **demo profile**：`docker compose --profile demo` 起 postgres:16 + 自动执行 `seed-demo.sql`（库名 `new_api_demo` 与脚本闸门一致）。
5. **healthcheck**：`/api/health` 返回 ≥500（如 DB 未配置的 503）视为 unhealthy，符合「连库失败即不健康」的部署语义。
