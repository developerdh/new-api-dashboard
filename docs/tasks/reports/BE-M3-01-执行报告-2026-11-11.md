## 3. 口径定稿

1. **数据集**：`usersRanking` / `trend` / `modelsRanking` / `userModels`；参数复用公共 Zod schema；`userModels` 必须带 `userId`（缺失 400，防全库导出）。
2. **CSV**：UTF-8 BOM、英文表头、`\r\n`、引号/逗号/换行转义；文件名 `dashboard-<dataset>-<start>-<end>.csv`；`Content-Disposition: attachment`。
3. **导出数据源**：`usersRanking` → `getUserRanking`；`trend` → `getTrend`（compare=none，粒度缺省 day）；`modelsRanking` → 与页面同 key 的 `cachedQuery` + `runModelRankingQuery`；`userModels` → `runUserModelsQuery` + 同 key 缓存。均与页面同 SQL 口径。
4. **限流**：进程内滑动窗口（60s/10 次/IP，`x-forwarded-for` 首段）；429 体 `{ ok:false, error:{ code:"rate_limited" } }` + `Retry-After`。
5. **上限**：排行类 `limit ≤ 100`；trend 桶数沿用 1000 上限。
