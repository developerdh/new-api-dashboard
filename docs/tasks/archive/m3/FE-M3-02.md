## 风险/阻塞
- 内联运行时使导出件偏大（echarts.min.js ≈ 1.12MB + option）：接受该体积换取「离线可交互」硬判据；未做 gzip/外链（自包含优先）。
- option 中的函数（tooltip/axis formatter）无法 JSON 序列化：导出后退回 ECharts 默认格式化，交互与数据不变（已在变更记录留结论）。
- 运行时来源为 `node_modules/echarts/dist/echarts.min.js`（项目根 cwd 相对路径）：`next start` 下可用；若未来改用 standalone 打包，需确认该文件随产物复制（INF-M4-01 注意）。
- 浏览器交互（导出/离线打开）未自动化，挂 LH-07。
