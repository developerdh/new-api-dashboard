## 本任务关键口径摘要
- 访问控制选型：**默认 Next 中间件 HTTP Basic Auth**（`DASHBOARD_AUTH_USER/PASS` env；实现内网 Nginx 之外的应用层兜底，无需数据库/外部 IdP）；NextAuth/OAuth 为备选，若用户后续要接入统一身份则另立卡（BACKLOG 已可登记）。
- 豁免路径：`/api/health`（探针）、`/login` 类静态外；admin/api/dashboard 全量受保护；`matcher` 排除 `_next/static`、图片。
- Basic Auth 凭据比较用 timingSafeEqual；`PASS` 未配置时**拒绝启动**（fail-fast，防裸奔上线）。
- 快照目录保护（§11.2「快照目录单独加访问密码」）：`public/snapshots` 不再静态直放——快照写入改由受保护路由 `/api/snapshots/[file]` 读取输出（含文件名白名单正则防穿越）。**此项触发 §8.2 归档路径口径偏差：预计需回流**（方案原文归档到 public/snapshots；改动点在访问控制层）——执行前输出《回流说明》交用户决策。
- 安全收口核验清单（逐条取证入执行记录）：① 全 API Zod 参数校验覆盖 ② 全查询参数化（grep 无模板字符串拼 SQL）③ 只读账号 + statement_timeout ④ 导出/快照限流在位 ⑤ 缓存 key 白名单与长度限制 ⑥ `.env` 不入 git、错误响应不回显连接串。
