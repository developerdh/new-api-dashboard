# BE-M1-02 · GET /api/overview 全局总览

> 里程碑：M1 · 核心统计 API ｜ 类型：新增 ｜ 预估：0.5 人日 ｜ 复杂度：S ｜ 状态：done

## 目标
`GET /api/overview` 返回时间范围内总消耗额度、总请求数、总 Token（输入/输出/总计）、活跃用户数、模型数量，接入 60s 缓存，口径与直连 SQL 一致。

## 输入/必读文档
- [ ] `docs/方案.md` §3.1（全局总览维度）、§4（接口清单）、§5.1（总览 SQL + logs 请求数 SQL）、§6.3(3)（TTL 60s）
- [ ] `src/server/queries/common.ts`（BE-M1-01）、`docs/db-schema-notes.md`、根 `AGENTS.md`（指针）

## 本任务关键口径摘要
- SQL：quota_data 聚合 `SUM(quota/token_used/prompt_tokens/completion_tokens)`（§5.1，`COALESCE(...,0)`）；`COUNT(*) FROM logs` 得请求数；活跃用户 `COUNT(DISTINCT user_id)`、模型数 `COUNT(DISTINCT model_name)` 取 quota_data 范围口径。
- 响应 data：`{ totalQuota, requestCount, totalTokens, promptTokens, completionTokens, activeUsers, modelCount }`；数值为整数，quota 原值透传（前端负责除以 New API 额度换算显示，属展示层）。
- 缓存：scope=`overview`，key 含 start/end，TTL 60s。
- 参数：`start`/`end`（必填？——定为**可缺省，默认今日**（Asia/Shanghai 自然日），结论落变更记录）。
