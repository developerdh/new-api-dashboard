# BE-M1-04 · GET /api/users/ranking 用户消耗排行

> 里程碑：M1 · 核心统计 API ｜ 类型：新增 ｜ 预估：0.5 人日 ｜ 复杂度：S ｜ 状态：done

## 目标
`GET /api/users/ranking` 返回范围内按消耗额度排序的 Top N 用户（消耗/请求数/Token），TTL 120s。

## 输入/必读文档
- [ ] `docs/方案.md` §3.3（排行榜维度）、§4（limit 参数）、§5.7（排行 SQL）
- [ ] `src/server/queries/common.ts`（BE-M1-01）、根 `AGENTS.md`（指针）

## 本任务关键口径摘要
- 主 SQL §5.7：quota_data 按 `(user_id, username)` 聚合 `SUM(quota)`、`SUM(token_used)`，`ORDER BY total_quota DESC LIMIT $n`。
- 请求数列：对入选的 Top N `user_id` 批量 `COUNT(*) FROM logs GROUP BY user_id` 二次查询合并（避免大 JOIN；N≤100 时 IN 列表可控）。
- 响应行：`{ userId, username, totalQuota, requestCount, totalTokens }`；`limit` 默认 20、上限 100（§4 收紧口径）。
- 缓存 scope=`usersRanking`，TTL 120s（§6.3(3)）。
