# FE-M3-02 · 前端单图导出（自包含 HTML 模板）

## 目标
全站 ECharts 图表统一具备「导出单图 HTML」按钮，导出文件打开后保留 tooltip/图例/缩放交互（方案 §8.1）。

## 输入/必读文档
- [ ] `docs/方案.md` §8.1（自包含 HTML 模板 + `getOption()` 序列化 + echarts 运行时内联）
- [ ] `src/components/charts/EChart.tsx`（FE-M2-01 已留导出插槽）、根 `AGENTS.md`（指针）

## 本任务关键口径摘要
- 在 EChart 封装层加 `exportable` prop（默认 true），工具区按钮以自绘模板生成自包含 HTML：`getOption()` 序列化 + 内联 echarts 运行时（取本地产物，不用外网 CDN）。
- **执行前置校验已完成**（INF-M0-01）：echarts 5.6.0 / 6.1.0 包内均无 `exportToHTML`；方案 §8.1 已于 2026-10-09 按回流批准改口径，本卡按新口径实现，不再写 `exportToHTML`。
- filename 命名：`<scope>-<start>_<end>.html`（URL 参数取值，含时间范围可分享口径）。
- 主题：导出文件按当前页面主题生成 option（暗色 option 内联）。
