## 收尾动作 checklist（完成时逐项执行）
1. 代码 + 测试通过（命令见验收标准）
2. 本任务变更记录 + 续作区同步（done；断点备注清空或收敛进变更记录）
3. 遗留事项登记：① 承接的上游遗留 → 处理并闭合（看板遗留表删行）；② 本任务产出的向前引用 → 登记看板遗留表 open 行 + 受影响任务承接点
4. 回流：需要改 `docs/方案.md` → 在对话中输出《回流说明》（改动点/原因/回滚方式），经用户决策后执行，并在变更记录留一行结论留痕
5. 写任务执行报告（`reports/<编号>-执行报告-<日期>.md`；终点文档，其他文档不引用它）
6. 归档：本卡移入 `archive/<里程碑目录>/`；`COMPLETED.md` 登记一行（遗留列填 LH 编号或「无」）
7. 滚动归档检查：已收口里程碑段是否满足归档触发条件（见 `AGENTS.md`）
8. 同步看板：指针推进；在办表移除本行；遗留表同步
9. 一致性校验通过：`node docs/tasks/validate-tasks.mjs`（ERROR 清零，WARN 可接受）
