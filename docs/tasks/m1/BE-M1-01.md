## 本任务关键口径摘要
- 参数（§4）：`start`/`end` 接受 ISO 字符串或 Unix 秒 → 统一转整数 Unix 秒，`[start, end)` 左闭右开；`granularity` enum day|week|month；`userId` 正整数；`modelName` 白名单正则（字母数字符号，≤128）；`limit` 1–500 默认 20。
- 校验失败：HTTP 400 + `{ ok: false, error: { code: 'invalid_query', issues: [...] } }`（Zod flatten）；查询异常：500 + `{ ok: false, error: { code: 'query_failed' } }`（不回显 SQL/连接串——敏感信息红线）。
- 时间工具：`shanghaiDay(ts)` 等基于 `Asia/Shanghai` 的自然日/周/月边界换算（给趋势与环比用）；`prevRange(start,end,granularity)` 环比区间、`yoyRange` 同比区间（§3.2）。
- 缓存接入约定：route → `getOrCache(cacheKey(scope, params), TTL[scope], () => query)`；scope 常量与 TTL 表对齐 BE-M0-04。
- 统一响应：成功 `{ ok: true, data, meta: { range, granularity, cached } }`。
