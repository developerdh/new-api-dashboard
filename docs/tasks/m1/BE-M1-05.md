# BE-M1-05 · 单用户统计 API（/api/users/[id]/{overview,trend,models}）

> 里程碑：M1 · 核心统计 API ｜ 类型：新增 ｜ 预估：1 人日 ｜ 复杂度：M ｜ 状态：todo

## 目标
三个单用户端点就绪：总览（消耗/请求/Token/活跃天数）、趋势（day/week/month）、模型分布（含输入输出占比与最近使用记录），TTL 30s。

## 输入/必读文档
- [ ] `docs/方案.md` §3.3（单用户详情页数据项）、§4（/api/users/:id/* 清单）、§5.5（单用户趋势 SQL）、§5.6（模型分布 SQL）
- [ ] `src/server/queries/common.ts`（BE-M1-01）、`src/server/queries/user.ts`（BE-M1-04 已建，本卡扩展）、根 `AGENTS.md`（指针）

## 本任务关键口径摘要
- `/overview`：该用户区间内 `SUM(quota/token_used/prompt/completion)`（§5.5 聚合改全区间）、请求数 logs `COUNT(*)`、**活跃天数**=区间内 `COUNT(DISTINCT (created_at/86400 取上海自然日))`（桶去重实现）。
- `/trend`：§5.5 按 granularity 复用 BE-M1-03 桶逻辑（userId 过滤）。
- `/models`：§5.6 `GROUP BY model_name ORDER BY total_quota DESC`；行内附 prompt/completion 占比；另含 `recent`：logs 最近 50 条 `{createdAt, modelName, quota, promptTokens, completionTokens}`（§3.3「最近使用记录」）。
- 路径参数 `id`：正整数校验，非法 400；用户不存在返回 `ok:true` 空数据（区间内无记录 ≠ 404，避免探测用户存在性）。
- 缓存 scope=`userTrend`/`modelDist`，TTL 30s（§6.3(3)）。
