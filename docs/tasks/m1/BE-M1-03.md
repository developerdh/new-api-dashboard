# BE-M1-03 · GET /api/trend 全局趋势（day/week/month + 环比同比）

> 里程碑：M1 · 核心统计 API ｜ 类型：新增 ｜ 预估：1 人日 ｜ 复杂度：M ｜ 状态：todo

## 目标
`GET /api/trend?granularity=day|week|month` 返回范围内消耗/请求数/Token/活跃用户的时间序列，支持 compare 参数返回环比/同比对齐序列。

## 输入/必读文档
- [ ] `docs/方案.md` §3.2（趋势与环比同比）、§4（granularity 参数）、§5.2–5.4（天/周/月 SQL）
- [ ] `src/server/queries/common.ts`（BE-M1-01，含 prevRange/yoyRange）、根 `AGENTS.md`（指针）

## 本任务关键口径摘要
- SQL 按 §5.2–5.4：`DATE_TRUNC('<granularity>', to_timestamp(created_at) AT TIME ZONE 'Asia/Shanghai')` 分组，quota_data 聚合 total_quota/total_tokens/prompt/completion；活跃用户=桶内 `COUNT(DISTINCT user_id)`（quota_data）。
- 请求数趋势：logs 同粒度 `COUNT(*)`（§5.1 口径延伸到桶维度），与 quota_data 序列按桶时间戳合并。
- `compare` 参数：`none|prev|yoy`；prev=同长度前一周期，yoy=去年同期；响应附 `compareSeries`（按序对齐，长度不足补 null）。
- 缓存 TTL：覆盖当前时间所在桶 → 60s；完全历史范围 → 3600s（§6.3(3) 历史月度 1h 延伸口径，结论落变更记录）。

- `DATE_TRUNC('week')` 默认周一（ISO）——与 New API 页面周口径若不同，以方案 SQL 为准，不在本卡改动。
